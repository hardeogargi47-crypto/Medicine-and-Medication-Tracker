## Project Overview

The **Medicine & Medication Tracker** is a Python-based application developed to help users organize and keep track of their medicines and medication schedules in a simple and structured way. The project is designed as a beginner-friendly Python application that demonstrates how programming concepts such as **functions, lists, dictionaries, loops, conditional statements, user input, file handling, and JSON data storage** can be combined to create a useful real-world application.

The application provides a menu-driven interface through which users can add medicines, view their saved medicines, search for a particular medicine, record whether a medicine has been taken, reset the daily medication status, and delete medicines that are no longer required.

The main purpose of this project is to demonstrate how Python can be used to solve a practical day-to-day organizational problem while maintaining a simple and understandable program structure.

---

## Objectives

The main objectives of this project are:

* To develop a simple medication management system using Python.
* To help users maintain a record of their medicines.
* To store important medication details such as medicine name, dosage, timing, and duration.
* To allow users to easily search and view their medicines.
* To provide a feature for marking medicines as taken.
* To maintain medication information even after the program is closed.
* To demonstrate the practical use of Python file handling and JSON.
* To apply fundamental programming concepts to a real-world project.

## Key Features

### 1. ➕ Add Medicine

Users can add a new medicine by entering:

* Medicine name
* Dosage
* Intake time
* Start date
* End date

The information is automatically stored in the application's data file.

### 2. View Medicines

The application displays all medicines currently stored in the system along with their:

* ID
* Name
* Dosage
* Intake time
* Start date
* End date
* Current status

This makes it easy to view the complete medication schedule in one place.

### 3. Search Medicine

Users can search for a particular medicine by entering its name. The application checks the stored records and displays the relevant medicine details.

This feature demonstrates how Python can be used to search through data stored in lists and dictionaries.
