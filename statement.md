# Problem Statement

## Problem

People who take medicines regularly may find it difficult to keep track of medicine names, dosage information, intake timings, and medication duration. Forgetting whether a medicine has already been taken can also make daily medication management confusing.

The **Medicine & Medication Tracker** is a Python-based project designed to provide a simple and organized way to record and manage medicine information. The application allows users to store medicine details and track whether a medicine has been taken.

## Scope of the Project

The scope of this project is to develop a simple, user-friendly, menu-driven Python application for organizing medication records.

The project includes the following functions:

- Adding a new medicine
- Recording medicine name and dosage
- Recording the scheduled intake time
- Recording the start and end dates of medication
- Viewing all stored medicines
- Searching for a particular medicine
- Marking a medicine as taken
- Resetting the daily medication status
- Deleting a medicine record
- Saving medicine information using a JSON file

The project focuses on medication organization and tracking. It is an educational software project and does not provide medical advice, diagnosis, prescriptions, or treatment recommendations.

## Target Users

The intended users of this project include:

- Students and beginners learning Python programming
- Individuals who want a simple way to organize sample medication records
- Users interested in understanding how a basic medication-tracking application works
- Developers and learners who want to study file handling, JSON, functions, lists, dictionaries, loops, and conditional statements through a practical project

For safety, actual medication schedules should always be based on instructions from a qualified healthcare professional or the medicine's official label.

## High-Level Features

### 1. Add Medicine

The user can enter important information about a medicine, including:

- Medicine name
- Dosage
- Intake time
- Start date
- End date

### 2. View Medicines

The application displays all stored medicine records along with their details and current taken/not-taken status.

### 3. Search Medicine

The user can search for a medicine by entering its name. The application searches the stored records and displays matching information.

### 4. Mark Medicine as Taken

The user can select a medicine using its ID and mark it as taken. The updated status is saved in the JSON data file.

### 5. Reset Daily Status

The user can reset the taken status of the medicines so that the tracker can be used for another medication-tracking cycle.

### 6. Delete Medicine

The user can delete an existing medicine record using its unique ID.

### 7. Data Storage

Medicine information is stored in a JSON file so that the records remain available when the application is closed and opened again.

### 8. Menu-Driven Interface

The application provides a simple command-line menu that allows users to select different operations and navigate through the tracker easily.

## Project Outcome

The expected outcome of this project is a functional Python application that demonstrates how basic programming concepts can be combined to solve a practical organizational problem. The project also provides hands-on experience with Python functions, data structures, loops, conditional statements, file handling, JSON, and basic project organization.
